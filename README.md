Tired of scrolling through the same generic "Top 10 Bali Spots" lists?
CariBali helps travelers cut through the noise and find Bali destinations
that actually match what they're looking for — filtered by category and
location in seconds, not scrolling.

- 🔍 Filter destinations instantly by category (Culture, Nature, Adventure, Wildlife, Beach, Wellness) and location
- ⭐ Discover hidden gems in the top-rated Explore Bali carousel
- 🗺️ Jump straight to Google Maps for any listed spot
- 🔐 Admin-only dashboard keeps the destination catalog fresh and accurate
- 📱 Fully responsive, works great on any device

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Laravel 12 (PHP 8.2+) |
| Auth | Laravel Jetstream 5 + Fortify |
| Frontend | Blade, Tailwind CSS 3, Vite 6 |
| Database | MySQL |
| Admin UI | Bootstrap (bundled admin template) |

## Environment Variables

| Variable | Description |
|---|---|
| `APP_KEY` | App encryption key — auto-generated by `php artisan key:generate`, don't set manually |
| `DB_CONNECTION`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` | Your local database connection (MySQL recommended; SQLite also works) |
| `MAIL_*` | Only needed if you want password-reset emails to actually send; defaults to logging emails locally |

No third-party API keys are required — the app doesn't call any external services.

## Cara Instalasi & Menjalankan

Prasyarat: PHP 8.2+, Composer, Node.js 18+ & npm, MySQL server (atau SQLite).

```bash
# 1. Clone repository
git clone <repository-url> caribali
cd caribali

# 2. Install dependencies
composer install
npm install

# 3. Setup environment
cp .env.example .env
php artisan key:generate

# 4. Setup database (isi kredensial DB di .env dulu)
php artisan migrate --seed

# 5. Jalankan aplikasi
composer dev
```

Script tambahan:

```bash
npm run build   # build asset untuk production
php artisan test  # jalankan test suite
```
